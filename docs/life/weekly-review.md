> 示例文章：这里演示生活记录的写法，可以按自己的习惯删改。

周回顾的目的不是为每个小时打分，而是从一周的事实中发现节奏问题，并为下一周做少量、明确的调整。

## 先收集事实

回看日历、任务列表、笔记和照片，先记录发生了什么，不急着评价：

- 完成的三件重要事情。
- 没有完成但仍然重要的事情。
- 临时出现并占用时间的事情。
- 一次值得保留的体验或对话。

事实记录足够简短即可。持续数月后，它会比依赖记忆更容易看出真实趋势。

## 检查精力而不只是产出

同样的结果可能来自完全不同的消耗。可以为以下维度各写一句话：

| 维度 | 回顾问题 |
| --- | --- |
| 睡眠 | 起床和入睡时间是否稳定？ |
| 专注 | 哪些时段最容易进入深度工作？ |
| 身体 | 是否保持基本运动和休息？ |
| 情绪 | 什么事情持续占据注意力？ |
| 关系 | 是否留出了不被任务支配的时间？ |

## 只决定少数下一步

下一周不需要一份理想生活清单。选择一个必须推进的结果、一项需要维护的习惯，以及一个主动放弃的事项，通常已经足够。

```text
重要结果：完成论文实验的第一轮对照组
维护习惯：工作日 00:00 前停止使用电脑
主动放弃：本周不继续比较新的笔记工具
```

## 模板

```markdown
## 本周事实
- 完成：
- 未完成：
- 意外事项：

## 精力与节奏
- 有效的安排：
- 消耗最大的事情：

## 下周调整
- 最重要的结果：
- 继续维护：
- 暂时不做：
```

一套回顾方法是否有效，取决于它能否持续。模板越短，越有机会在忙碌的一周之后仍然被使用。
